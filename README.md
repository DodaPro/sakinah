# 🕌 سَكِينَة | Sakinah

> تطبيق ويب إسلامي شامل + نظام تحدي مذاكرة — في مكان واحد منظم

**سَكِينَة** تطبيق ويب متكامل يجمع بين العبادات والتنظيم والإنتاجية: مواقيت الصلاة التلقائية، القرآن الكريم بأصوات نخبة القراء، الأذكار المتجددة، ونظام تحدي مذاكرة كامل بالمهام والتايمر والأوسمة — كل ذلك بواجهة عربية (RTL) جميلة مع ثيمات متعددة وأنميشنات هادئة.

---

## ✨ المميزات

### 🕌 الصلوات
- **مواقيت الصلاة تلقائيًا** حسب موقعك (GPS أو إحداثيات يدوية) بخمس طرق حساب مختلفة
- عداد حي للصلاة القادمة + التاريخ الهجري + اتجاه القبلة
- نافذة **«هل صليت؟»** بعد كل صلاة: تأكيد = نقاط XP + ألعاب نارية 🎆 + تهنئة / رفض = نصيحة مؤثرة + آية قرآنية
- **الأذان** بصوت mp3 حقيقي مع عدة أصوات للاختيار + نغمة احتياطية محلية
- **تذكير الأذان** بإشعارات المتصفح: تنبيه مبكر قبل الأذان (٥/١٠/١٥ دقيقة) وعند كل أذان
- سجل صلوات 90 يومًا + سلسلة الأيام المتتالية

### 📖 القرآن الكريم
- **١٧ قارئًا** نخبة (العفاسي، عبد الباسط، الحصري، المنشاوي، ماهر المعيقلي، سعد الغامدي...)
- كل السور (١١٤) مع مشغل تلاوة كامل (تشغيل/إيقاف/سابق/تالي/شريط تقدم قابل للسحب + تقديم/رجوع ١٠ ثواني)
- تشغيل تلقائي متسلسل للسور + بحث + مفضلة + تلاوة الآيات المفردة

### 🤲 الأذكار والحصن والورد (جديد)
- **أذكار الصباح والمساء**: ٢٣ ذكرًا ثابتًا لكل فترة بعدّاد لكل ذكر يتجدد يوميًا وشريط تقدم
- **حصن المسلم كاملًا**: ١٣٣ بابًا و٣٠٢ ذكرًا/دعاءً مع المصادر + بحث ذكي يتجاوز التشكيل + صوت لكل باب + نسخ سريع
- **خطة ورد القرآن**: ختمة يومية بأهداف جاهزة (جزء/نص جزء/مخصص) مع تتبع الصفحات وسلسلة الأيام والختم المتوقع وألعاب نارية عند إتمام الورد
- **تلاوة الآية المتجددة تلقائيًا**: أول ما الآية تتغير كل دقيقة يشتغل صوت تلاوتها (اختياري من الإعدادات)

### ⏱️ التاسكات والتايمر ووقت المذاكرة
- كورسات دراسية بتوزيع تلقائي على الأيام + مهام يومية قابلة للتعديل
- تايمر مذاكرة **مربوط بالمهام**: شغّل الجلسة من المهمة مباشرة، والوقت يُجمع عليها
- التايمر يستمر حتى بعد إغلاق الصفحة (timestamp-based)
- صفحة **وقت المذاكرة** بالإحصائيات: إجمالي الأسبوع، المتوسط اليومي، أفضل يوم، رسم بياني بخط الهدف، الوقت حسب المادة، آخر ٣٠ جلسة

### 🏅 إنجازاتي
- نظام **XP** موحد: صلاة +١٠، مهمة +٥، كل ٥ دقائق مذاكرة +١، وسام جديد +٢٠
- مستويات تتقدم تلقائيًا (كل ١٠٠ XP)
- **٢١ وسامًا** مقسمة على أوسمة الصلوات وأوسمة المذاكرة والمهام

### 📝 ملاحظاتي (جديد)
- نوتات سريعة بشيك بوكس (خلصتها/لسه) وحذف
- **تذكير اختياري**: حدد ميعاد وينبّهك الموقع بالملاحظة (إشعار + تنبيه داخل التطبيق)
- **حذف تلقائي اختياري**: الملاحظة تتمسح لوحدها في الميعاد اللي تحدده

### ⚙️ الإعدادات والمظهر
- **٩ ثيمات جاهزة** + تغيير الألوان حسب مزاجك بحرية كاملة
- مفتاح تحكم في الأنميشنات (خلفية متحركة بالنجوم، ألعاب نارية...)
- كل شيء يُحفظ محليًا في المتصفح (localStorage) — بياناتك عندك وحدك

## 🚀 التشغيل محليًا

```bash
# 1) نسخ المشروع
git clone https://github.com/USERNAME/sakinah.git
cd sakinah

# 2) تثبيت الحزم
npm install
# أو
bun install

# 3) تشغيل وضع التطوير
npm run dev

# 4) افتح المتصفح على
# http://localhost:3000
```

> 💡 التطبيق يعمل بالكامل دون قاعدة بيانات — كل بياناتك (الصلوات، المهام، الجلسات، الأوسمة، الثيمات) تُحفظ محليًا في متصفحك عبر localStorage.

### بناء نسخة الإنتاج

```bash
npm run build
npm start
```

## 🌍 النشر على الإنترنت (لينك عام يستخدمه أي حد)

أسهل طريقة لنشر التطبيق مجانًا هي [Vercel](https://vercel.com) — وهي المنصة الرسمية لـ Next.js:

1. ارفع المشروع على GitHub أولًا (أنشئ مستودعًا جديدًا وارفع الملفات إليه)
2. ادخل على [vercel.com](https://vercel.com) وأنشئ حسابًا باختيار **Continue with GitHub**
3. من لوحة التحكم: **Add New → Project** ثم اختر مستودع `sakinah`
4. اضغط **Deploy** وانتظر دقيقة — كل شيء مضبوط تلقائيًا ✅
5. ستحصل على لينك دائم مثل: `https://sakinah-yourname.vercel.app` — شاركه مع أي شخص!

> 💡 كل تعديل جديد تدفعه (push) إلى GitHub يُنشر تلقائيًا على الموقع دون أي خطوات إضافية.
>
> 🔒 لا حاجة لأي قاعدة بيانات أو متغيرات بيئة — بيانات المستخدم تُحفظ محليًا في متصفح كل زائر.
